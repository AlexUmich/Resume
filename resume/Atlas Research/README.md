# Autotensioning Program
This was one of many programs used in our lab, which I wrote in its entirety. However, it also calls upon a few other files that were contributed by others.

This program creates the main GUI, controls a stepper motor that autonomously tensions/incrementally edits the wires within our manufactured tubes, and calls on other files that I partially contributed to, one to create a real-time tension graph and one to calculate the exact tension.

Full lab codebase: https://github.com/dravinflores/smdt
